# GURUKUL AI (गुरुकुल AI)

> **Hindi-first, Socratic 3D AI Tutor & Learning Platform for Classes 1 to 12**  
> Tailored for state curriculum boards (including all 24 districts of Jharkhand, India) with 100% offline-first capability.

---

## 🌟 Key Features

1. **3D Knowledge Orb & Sacred Geometry Engine**:
   - Interactive Three.js 3D core with rotating orbital rings, floating knowledge particles, and mouse-reactive perspective tilt.
2. **Socratic AI Tutor**:
   - Rather than dumping answers, provides understanding, hints, guided step-by-step reasoning, and final answers in Hindi, English, and Hinglish.
3. **Multimodal Inputs**:
   - **Voice Speech-to-Speech**: Live audio recognition and Hindi TTS speech playback with animated soundwaves.
   - **Photo OCR Question Extractor**: Upload or take photos of textbook questions with animated laser scan extraction.
4. **Offline-First Resilience**:
   - Local IndexedDB (`packs`, `queue`, `kv`, `tts`) allows complete chapter learning, practice quizzes, and offline doubt queueing without internet.
5. **District & Grade Customization**:
   - Full support for Classes 1–12 across the 24 districts of Jharkhand (Ranchi, Dhanbad, Bokaro, Deoghar, etc.).
6. **Guardian & Teacher Monitoring**:
   - 6-character link code verification (`GK8821`), subject mastery breakdown, and study time analytics.

## 🚀 Quick Start

```bash
# Navigate to the project directory
cd "C:\Users\Project\Gurukul AI"

# Install dependencies (already installed)
npm install

# Start local development server
npm run dev

# Or build for production
npm run build
```

Open your browser at: `http://localhost:3000` (or the port Vite outputs).
